# Tampilan panel lebih tertata dan CVE Advisor

## ✨ Fitur Baru
- Daftar URL WAF (Whitelist dan Blacklist) mendukung mode Normal (awalan path biasa, mis. /api/v1/orders) dan Regex, dan setiap entri bisa diubah langsung dari tabel. URL Whitelist punya cakupan Semua WAF atau Hanya OWASP CRS: pilihan kedua mempercepat endpoint API JSON tepercaya sementara aturan ZySentinel (berkas sensitif, webshell, pemindai) tetap aktif
- Susunan menu baru: Dashboard | Antivirus | Firewall | WAF | Audit | Logs | Settings. Dashboard kini hanya ringkasan; daftar IP diblokir, antrean review, asal serangan, dan Learned Rules pindah ke Firewall; Event Feed, EDR, log aksi, riwayat IP, statistik vhost, situs terpantau, dan log daemon pindah ke Logs; notifikasi pindah ke Settings
- Tab Audit dengan CVE Advisor: inventaris web server, PHP, paket sistem, serta WordPress core dan plugin per situs, skor postur keamanan, dan rekomendasi perbaikan (pengetatan konfigurasi dan perintah update)
- Inventaris port terbuka di Firewall > Port Control: port yang sedang listening, alamat bind (publik atau lokal), proses pemiliknya, dan saran pengetatan
- Dialog progres pemindaian CVE interaktif dan inventaris komponen multi-stack: deteksi runtime (PHP, Python, Node.js, Go), webserver (Nginx, Caddy, Apache, LiteSpeed, OpenLiteSpeed), database (MariaDB/MySQL, Redis), OS/Kernel, Docker, dan panel kontrol (aaPanel, cPanel, DirectAdmin, CyberPanel, Standalone)
- Kolom Response pada Event Feeds: menampilkan kode status HTTP untuk setiap URI kejadian dengan pewarnaan respons dan layout tabel tetap tanpa overflow

## 🔧 Perbaikan & Peningkatan
- Langganan: tombol Stop langganan di dialog Plans & Upgrade (kapan saja, tanpa refund, paket tetap aktif sampai akhir periode); tombol Perpanjang/Upgrade/Downgrade mengikuti paket aktif, downgrade tersedia setelah masa bayar berakhir termasuk masa tenggang
- CVE Advisor tidak menandai paket bawaan distro (apt/dnf) sebagai rentan hanya dari nomor versi, karena distro menambal tanpa menaikkan versi; untuk paket itu pakai update keamanan distro
- Data kerentanan bawaan dikoreksi dan hanya memuat advisori resmi yang terverifikasi
- Indikator status Defense Mode dan Panic dipindahkan ke header panel sejajar dengan status lisensi, lengkap dengan dialog modal informasi saat diklik dan perbaikan kontras teks

## 🐛 Fix Bug
- Pembaruan basis data virus ClamAV dari panel tidak lagi gagal saat layanan pembaruan otomatis ClamAV berjalan; pembaruan signature rkhunter di Debian/Ubuntu (dinonaktifkan distro) kini dilewati dengan penjelasan, bukan dilaporkan gagal
- Lencana lisensi di header tidak lagi menampilkan "Free" sebelum status lisensi selesai dimuat
- Pemindaian WordPress tidak lagi bisa menggantung pada berkas khusus di folder situs dan tidak mengikuti tautan simbolik ke luar situs
- Nilai di tabel inventaris port dan CVE Advisor ditampilkan aman (di-escape)
- Label lisensi kini dapat diklik langsung saat plugin pertama kali dibuka tanpa perlu menutup dan membuka kembali panel
- Pemindai CVE tidak lagi menjalankan program milik akun lain dengan hak root; program milik akun layanan (mis. redis) dijalankan sebagai akun itu
- Kolom Response di Event Feeds hanya mengambil kode dari permintaan IP yang sama dan aman terhadap URI berbentuk opsi perintah
- Komponen yang tidak memiliki data kerentanan kini berlabel "Tidak dinilai", bukan "Aman"; versi sistem operasi terdeteksi benar di Ubuntu/Debian
- Dialog status Defense Mode dan Panic di header kini menampilkan isinya; pemindaian CVE yang gagal tidak lagi dilaporkan berhasil
- Daftar paket dan harga di dialog Plans & Upgrade kini dapat dimuat (sebelumnya ditolak Cloudflare)
- Daftar IP WAF menolak entri yang memuat karakter kontrol (baris baru) dan rentang yang lebih luas dari /8; sebelumnya catatan berisi baris baru dapat menyisipkan entri 0.0.0.0/0 yang mematikan WAF
- Pemeriksaan sesi panel tidak lagi dilewati bila token sesi kosong (fail-closed)
- Reload nginx tidak lagi mematikan semua worker WAF ketika nginx sebelumnya dijalankan dari folder yang sudah dihapus; pemeriksaan berkala memulihkannya tanpa mencabut WAF
- Pemulihan berkas dari karantina antivirus menelusuri folder tujuan lewat file descriptor sehingga folder yang ditukar menjadi symlink tidak dapat mengarahkan berkas ke direktori sistem; tujuan di /tmp tidak lagi diterima
- Semua situs nginx dan Apache mendapat salinan access log di folder milik root yang tidak bisa dihapus atau disisipi akun web; log aaPanel tetap ditulis seperti biasa
- Log situs yang hanya dikunjungi lewat IPv6 kini ikut dipantau; pesan aturan WAF dan beberapa pesan pengaturan notifikasi kini tampil dalam bahasa Inggris saat bahasa panel Inggris
- Set Up Coraza menyesuaikan konektor dengan versi nginx yang aktif: setelah nginx di-upgrade (mis. 1.31.7 ke 1.31.8) modul lama tidak lagi dianggap siap dan konektor di-compile ulang untuk versi baru; setiap modul diuji muat ke nginx aktif sebelum disimpan atau dipasang, sehingga tidak lagi muncul galat "module ... version ... instead of ..." saat Pasang ke nginx
- Upgrade nginx di aaPanel tidak lagi mematikan situs saat Coraza aktif: sebelum nginx start, modul yang tidak cocok dilepas sementara, lalu konektor untuk versi baru dibangun dan dimuat otomatis dan proteksi situs dipulihkan dalam hitungan detik
- WAF tidak lagi tercabut sendiri setelah server reboot (pengaman salah menganggap nginx yang baru start sebagai macet)
- Dialog progres Coraza tidak lagi menunggu tanpa batas dengan log kosong: status job yang tidak terbaca dihentikan dengan pesan jelas, job yang lama tidak menulis keluaran diberi peringatan, dan job yang masih berjalan dari klik sebelumnya diberi tahu

## 🔒 Keamanan
- Pembaruan otomatis edisi Free kini mewajibkan signature digital release (Ed25519, `SHA256SUMS.txt.sig`) selain SHA-256; release tanpa signature yang sah ditolak, sehingga akun GitHub yang diambil alih tidak dapat mengirim paket palsu
- Rincian kartu Requests menampilkan jumlah baris log IPv6 yang hanya dilindungi WAF (penghitung skor dan blokir firewall saat ini hanya IPv4)
- Daftar komponen dan data pihak ketiga beserta lisensinya: `THIRD-PARTY-NOTICES.md`
