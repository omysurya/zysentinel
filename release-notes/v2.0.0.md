# Edisi baru dengan paket Free, Pro, dan Max

## ✨ Fitur Baru
- Paket langganan Free, Pro, dan Max: fitur berbayar tetap tampil di panel dengan badge paketnya, sehingga Anda tahu persis apa yang tersedia di tiap paket
- Edisi Free: fitur Pro & Max tampil dengan badge **SOON** dan belum dapat digunakan di edisi ini
- Channel update terpisah untuk Free dan Pro; update hanya memasang paket dari channel yang sesuai
- Versi plugin ditampilkan konsisten di seluruh panel (badge, status update, telemetri) dari satu sumber

## 🔧 Perbaikan & Peningkatan
- Versi naik ke 2.0.0 (format instalasi berlisensi dan channel update baru)
- Update mengambil checksum dari release yang sama dengan paketnya, bukan dari release terbaru lain
- Unit systemd merujuk dokumentasi resmi di GitHub, bukan jalur lokal server developer

## 🐛 Fix Bug
- Notifikasi yang dimatikan tidak lagi tetap mengantre di latar belakang (`notify_url = ""` kini benar-benar kosong; menghapus tujuan notifikasi di panel ikut mengosongkannya)
- Uninstall menunggu guardd benar-benar berhenti sebelum mencabut firewall dan file; tidak ada lagi proses yang tertinggal
- Restart di server tanpa systemd tidak lagi bisa berakhir tanpa daemon yang berjalan
- Paket release tidak lagi membawa file sisa pengembangan (`*.orig`, `*.rej`)

## 🔒 Keamanan
- Mesin antivirus premium tidak lagi berjalan tanpa paket yang sesuai (gagal tertutup)
